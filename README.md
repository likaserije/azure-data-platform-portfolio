# Azure Data Platform Portfolio

An end-to-end data platform project simulating a retail/e-commerce business,
built to demonstrate data solution architecture skills across data
engineering, analytics, data science, and cloud architecture design.

## Project structure
- [`data_engineering/`](data_engineering/) — Medallion (bronze/silver/gold)
  ELT pipeline on the Olist e-commerce dataset.
- [`data_analysis/`](data_analysis/) — SQL business analysis + interactive
  Power BI dashboard.
- [`data_science/`](data_science/) — Bad-review prediction model (Random
  Forest), deployed as a FastAPI service.
- [`architecture/`](architecture/) — Architecture Decision Records, Azure
  deployment (live, verified), and the overall system design.

## Tech stack
Python, pandas, DuckDB, scikit-learn, FastAPI, Power BI, Azure (Data Lake
Storage Gen2, Functions - designed).
